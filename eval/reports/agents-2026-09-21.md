## 3. 价值对照实验（PRODUCT §8，Claude Code 两臂）

任务对：任务1 = 修复 BOM bug（臂 B 额外带自主记录指引）；任务2 = 全新会话实现 `--lines-only`（臂 B 额外指示先检索共享库）。两臂独立项目副本（初始态完全一致：1 个失败用例）、同模型、同权限基线、原生记忆初始状态隔离。臂 A = 原生记忆（`--resume` 续会话，无服务）；臂 B = 原生记忆 + 服务（全新会话 + `search_entries`）。

| 指标（任务2） | 臂 A 原生记忆 | 臂 B 原生记忆+服务 |
|---|---|---|
| ① 功能验收点 | ✅ 6/6 测试绿、`--lines-only` 行为正确 | ✅ 7/7 测试绿、`--lines-only` 行为正确 |
| ② 用户重复转述次数 | 0（转录审计无用户提问） | 0（转录审计无用户提问） |
| ③ 旧内容误用 | 0（零依赖保持、无约定冲突） | 0（零依赖保持、无约定冲突） |
| ④ 任务2 墙钟 | 112.7s | 89.3s |
| ⑤ 任务2 token（in/cache_read/out） | 18,221 / 248,768 / 4,950 | 5,976 / 192,832 / 3,531 |
| 任务1 墙钟 | ≈236s（未计时，shell 等待回执） | 196.8s（`/usr/bin/time`） |

**如实结论（不预设收益）**：这个小任务下两臂均达标——臂 B 任务 2 更快（89.3s vs 112.7s）且输入 token 更少，检索直接拿到凝练约定；臂 A 靠原生记忆同样零转述完成任务。臂 B 的收益代价是会话 1 的额外记录开销与共享条目维护。任务规模小、单次运行，结论只适用于本设置；「减少重复转述/旧内容误用」的差异在本任务中未体现（两臂均为 0），需要更大或更久隔的任务才能区分。两臂的完整会话转录与 usage 在 `artifacts/`。
