# 星辰科技开放平台 API 限流政策（v1）

## 版本信息

本政策为星辰科技开放平台 API 限流政策的第 1 版（版本号 v1），生效日期为 2026 年 1 月 1 日，失效日期为 2026 年 6 月 30 日。自 2026 年 7 月 1 日起，本政策由第 2 版限流政策（v2）整体取代，取代后本版本仅作历史归档用途，不再作为限流判定的依据。

## 适用范围

本政策适用于所有通过星辰科技开放平台网关调用公开 API 的开发者与企业客户，覆盖免费层、基础层与企业层三个服务层级。沙箱环境与内部联调环境不受本政策约束。通过非官方渠道或绕过网关的调用行为按平台服务条款另行处理。

## 术语定义

时间窗口指以自然分钟为单位的滚动统计区间，窗口边界与协调世界时对齐。调用次数指单个 API 密钥在单个时间窗口内发起的请求总数。限额指平台允许该密钥在单个时间窗口内成功送达业务服务的请求上限，超过限额的请求在网关层被拒绝，不计入业务服务处理量。

## 各层级默认限额

### 免费层

免费层开发者每个 API 密钥的调用限额为每分钟 60 次，每日累计上限 5000 次。超出每日上限后，当日剩余时间内该密钥的所有请求都将被拒绝，次日零点自动恢复。免费层不支持定制限额，也不参与弹性余量机制。

### 基础层

基础层客户每个 API 密钥的调用限额为每分钟 300 次，每日累计上限 50000 次。基础层客户可为不同业务线申请最多 5 个独立密钥，各密钥限额分别计算，互不占用。密钥拆分申请通过工单提交，审批周期为三个工作日。

### 企业层

企业层客户每个 API 密钥的调用限额为每分钟 1200 次，每日累计上限 500000 次。企业层客户可申请定制限额，定制上限不得超过默认限额的三倍，定制合同按自然年签署。定制限额变更需在合同附件中列明生效日期与计量口径。

## 超限处理规则

当请求超出每分钟限额时，网关立即返回 429 状态码，响应头中携带当前时间窗口的剩余等待秒数，客户端应按该间隔退避重试。若同一密钥在连续三个时间窗口内均触发超限，平台将对该密钥执行降级处理：限额临时下调百分之五十，持续 24 小时，降级期间不接受加急解除申请。

对突发流量场景，平台提供每分钟 20% 的瞬时弹性余量，弹性余量仅对基础层及以上层级开放，且每个自然日最多触发三次。弹性余量用尽后，超出部分按普通超限规则处理。

## 计量口径

限流计量以网关实际接收的请求为准，包含失败请求与超时请求；缓存命中的响应不计入调用次数。批量接口按一次调用计一次，不按批量内条目数放大。重试请求按新请求计量，客户端应实现指数退避以避免重试风暴。

## 申诉与调整

客户对限流判定有异议时，可通过工单系统提交申诉并附上请求标识，平台承诺在两个工作日内响应。合同客户可在每季度末申请一次限额重估，重估结果自下一季度首日生效，重估期间维持原限额执行。申诉与重估不影响降级处理的执行。

本政策与《星辰科技数据保留政策》相互独立，限流记录的留存时长以数据保留政策为准。本政策由开放平台运营部负责解释。
