# 星辰科技开放平台 API 限流政策（v2）

## 版本信息

本政策为星辰科技开放平台 API 限流政策的第 2 版（版本号 v2），生效日期为 2026 年 7 月 1 日，为当前有效版本。本版取代 2026 年 1 月 1 日生效的第 1 版（v1），v1 已于 2026 年 6 月 30 日失效。限流判定一律以本版为准。

## 适用范围

本政策适用于所有通过星辰科技开放平台网关调用公开 API 的开发者与企业客户，覆盖免费层、基础层与企业层三个服务层级。沙箱环境与内部联调环境不受本政策约束。通过非官方渠道或绕过网关的调用行为按平台服务条款另行处理。

## 术语定义

时间窗口指以自然分钟为单位的滚动统计区间，窗口边界与协调世界时对齐。调用次数指单个 API 密钥在单个时间窗口内发起的请求总数。限额指平台允许该密钥在单个时间窗口内成功送达业务服务的请求上限，超过限额的请求在网关层被拒绝，不计入业务服务处理量。本节口径与 v1 保持一致。

## 各层级默认限额

### 免费层

免费层开发者每个 API 密钥的调用限额为每分钟 120 次，每日累计上限 10000 次。相较 v1 版本，免费层分钟限额由 60 次提升至 120 次，日累计上限由 5000 次提升至 10000 次。免费层仍不支持定制限额。

### 基础层

基础层客户每个 API 密钥的调用限额为每分钟 600 次，每日累计上限 100000 次。基础层客户可为不同业务线申请最多 8 个独立密钥（v1 为 5 个），各密钥限额分别计算，互不占用。密钥拆分申请通过工单提交，审批周期缩短为两个工作日。

### 企业层

企业层客户每个 API 密钥的调用限额为每分钟 2400 次，每日累计上限 1000000 次。企业层客户可申请定制限额，定制上限不得超过默认限额的四倍（v1 为三倍），定制合同按自然年签署。定制限额变更需在合同附件中列明生效日期与计量口径。

## 超限处理规则

当请求超出每分钟限额时，网关立即返回 429 状态码，响应头中携带当前时间窗口的剩余等待秒数。与 v1 不同，连续超限不再执行 24 小时降级，改为熔断机制：同一密钥在五分钟内第二次触发超限时，对该密钥熔断 10 分钟，熔断期间所有请求直接拒绝并提示熔断原因。熔断结束后限额自动恢复，不设累计惩罚。

突发流量弹性余量提升至每分钟 30%，覆盖全部层级（v1 仅覆盖基础层及以上），每个自然日最多触发次数由三次放宽为五次。弹性余量用尽后，超出部分按普通超限规则处理。

## 计量口径

限流计量以网关实际接收的请求为准，包含失败请求与超时请求；缓存命中的响应不计入调用次数。批量接口按一次调用计一次，不按批量内条目数放大。重试请求按新请求计量，客户端应实现指数退避以避免重试风暴。本节口径与 v1 保持一致。

## 申诉与调整

客户对限流判定有异议时，可通过工单系统提交申诉并附上请求标识，平台承诺在两个工作日内响应。v2 起新增自动告警：密钥用量达到限额的百分之八十时，平台向客户预留的告警渠道发送提醒。合同客户可在每季度末申请一次限额重估，重估结果自下一季度首日生效。申诉不影响熔断的执行。

本政策与《星辰科技数据保留政策》相互独立，限流记录的留存时长以数据保留政策当前有效版本为准。本政策由开放平台运营部负责解释。
